# Md Ali Haider — Developer Portfolio

A modern, responsive developer portfolio built with **React, Tailwind CSS, and GSAP**.

## 🌐 Live Website

**[mdalihaider.vercel.app](https://mdalihaider.vercel.app)**

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Modern dark UI with custom CSS variables
- GSAP-powered subtle animations
- Animated loading screen
- Smooth scrolling navigation
- Auto-hiding navbar on scroll
- Interactive skills section
- Project showcase with live demos and GitHub links
- Responsive contact section
- Custom footer with navigation and social links
- Resume access
- Reusable React components
- Centralized project and portfolio data

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/md-alihaider/portfolio-with-gsap.git
```

### Navigate to the project

```bash
cd portfolio-with-gsap
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```

## 🎨 Design & Animation

The portfolio focuses on a minimal, modern visual style with subtle interactions and animations.

GSAP is used for:

- Hero entrance animations
- Loading screen animation
- Scroll-triggered section animations
- Project reveal animations
- Contact and footer animations
- Interactive micro-animations

The goal is to keep animations **subtle and purposeful** rather than overwhelming the content.
